# Contributing

Start with the unchecked tasks in README. For a larger change, open an issue
describing the problem, intended behavior and how you will validate it.

For a pull request:
- Keep one concrete change per PR and explain its before/after behavior.
- Build against UE 5.8 and report the build result; say explicitly if you could not test it.
- For gameplay changes, include reproducible steps and a short PIE check.
- Do not introduce new paid dependencies without discussion.
- Do not upload engine source, marketplace packages, GTA assets, credentials or generated build files.
- Include only work you have the right to contribute, compatible with the repository's MIT license.

The private project's assets and integration setup are unavailable to contributors.
Prefer reproducible examples using primitives or clearly licensed original assets.
Unverified behavior and known limitations belong in the PR description.
